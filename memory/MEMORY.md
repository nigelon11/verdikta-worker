## Lessons Learned
- Digest format: Markdown with clickable links, under 4000 chars
- Always save files AND commit before logging
- GitHub token is missing `read:org` scope — github-monitor's "reviewer ghosted >72h" rule can't evaluate `reviewRequests` without it (no impact yet, no open PRs have pending review requests)
- The Bash tool also hard-blocks plain shell `>` redirection to any file regardless of path (separate from the `$SECRET`-expansion guard) — digest (2026-07-22) worked around it by using the Write tool to author JSON payloads directly and `curl -o` (not shell redirect) for responses
- `cp` between two paths inside the same allowed working directory is also blocked (new observation, write-tweet 2026-07-28) — use the Write tool instead of `cp` when copying/saving drafts
- digest/write-tweet/github-monitor/bd-radar/shiplog/mention-radar scratch workarounds (xAI payloads, fork/issue JSON dumps, count scripts, notify bodies) recur most runs; `rm` is blocked by the sandbox destructive-op gate so memory-flush can't clean them itself. **Checking `git status` alone isn't enough to confirm they're harmless** — real repo bloat, no secrets found, needs an actual cleanup PR (see Next Priorities). **Reproducible count method (fixed 2026-08-04, widened 2026-08-09/08-10, corrected/widened again 2026-08-11):** the narrow root-loose suffix pattern (`^tmp-|-tmp\.md$|-tmp\.json$`) was undercounting — a broad sweep (`git ls-files | grep -vE '/' | grep -iE 'tmp'`) found 21 root-level loose files, not 5 (missed names like `.bdtmp-xai-response.json`, `.runtmp_ghmonitor.md`, `xai-digest-tmp.json` — `tmp`/`-tmp`/`_tmp` placement varies by skill). Best recount command: `git ls-files | grep -icE 'tmp'` — don't trust a narrow suffix pattern for the loose count again, it silently missed 16 files for at least one prior flush cycle. None match `.gitignore`'s `tmp_*`/`.*-tmp.md` patterns. **2026-08-15 recount: 143** (flat vs 08-14, 2nd flat day in the last 3) — the underlying fix (cleanup PR + `.gitignore` extension) still hasn't shipped.
