## Lessons Learned
- Digest format: Markdown with clickable links, under 4000 chars
- Always save files AND commit before logging
- GitHub token is missing `read:org` scope — github-monitor's "reviewer ghosted >72h" rule can't evaluate `reviewRequests` without it (no impact yet, no open PRs have pending review requests)
- The Bash tool also hard-blocks plain shell `>` redirection to any file regardless of path (separate from the `$SECRET`-expansion guard) — digest (2026-07-22) worked around it by using the Write tool to author JSON payloads directly and `curl -o` (not shell redirect) for responses
- `cp` between two paths inside the same allowed working directory is also blocked (new observation, write-tweet 2026-07-28) — use the Write tool instead of `cp` when copying/saving drafts
- digest/write-tweet/github-monitor/bd-radar/shiplog scratch workarounds (xAI payloads, fork/issue JSON dumps, count scripts, notify bodies) recur most runs; `rm` is blocked by the sandbox destructive-op gate so memory-flush can't clean them itself. **Checking `git status` alone isn't enough to confirm they're harmless** — real repo bloat, no secrets found, needs an actual cleanup PR (see Next Priorities). **Reproducible count method (fixed 2026-08-04, pattern widened 2026-08-09):** `git ls-files | grep -E '(^|/)(\.runtmp|\.bdtmp|\.aeon-tmp|\.ghmon-tmp|\.wttmp|digest-tmp|tmp)(/|$)'` for dir-nested files plus `git ls-files | grep -E '^tmp-|-tmp\.md$|-tmp\.json$'` for root-level loose files — gives **116** as of 2026-08-09 (breakdown: `.runtmp/` 57, `.bdtmp/` 27, `.wttmp/` 9 [new dir, first committed 2026-08-09 — write-tweet's own scratch dir, missing from the pattern until this pass], `.aeon-tmp/` 5, `.ghmon-tmp/` 5, `tmp/` 5, `digest-tmp/` 3, root-level loose 5). Prior counts (97→99→105) are on a consistent basis but all *undercounted* `.wttmp/`; treat 116 as the corrected baseline, not a one-day +11 spike — re-verify the pattern covers every skill's scratch dir next time a new one appears (grep for `[a-z]+-tmp/` and `\.[a-z]+tmp/` to be safe going forward). None match `.gitignore`'s `tmp_*`/`.*-tmp.md` patterns (naming mismatch: `tmp-`/`-tmp`/`.runtmp` vs the covered `tmp_`)
